# FinTrack

# Modern personal finance dashboard built with React, TypeScript and Supabase.

## Organize your finances, track goals, analyze reports and manage your money through a modern, responsive and intuitive interface.

---

### Features

- Dashboard with financial overview
- Income and expense management
- Wallet and credit card management
- Financial goals with progress tracking
- Interactive reports and charts
- PDF report export
- User settings and preferences
- Dark mode
- Fully responsive design
- Authentication with Supabase

---

### Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Query
- React Hook Form
- Zod
- Recharts
- Supabase
- Vercel

### Getting Started

Clone the repository

```bash
git clone https://github.com/MKTTeus/fintrack.git
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Run the development server

```bash
npm run dev
```

Build

```bash
npm run build
```
